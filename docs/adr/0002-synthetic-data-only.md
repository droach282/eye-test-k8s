# Synthetic data only

No real game or poll data from CollegeFootballData (CFBD) is committed to this repository. Golden parity fixtures, the compose sample season and ingest-adapter tests all use synthetic or hand-written data. CFBD's terms bar redistributing raw data as a standalone dataset, bulk download or public database mirror, and this repository is public; the public site likewise returns only derived data. We gave up real-season parity checks and recorded API responses in exchange for staying clear of those terms.
